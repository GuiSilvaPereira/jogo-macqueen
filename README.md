# ⚡ Katchau! — jogo de carrinhos para crianças pequenas

Jogo feito para crianças de ~2 a 4 anos: botões gigantes, nada de texto obrigatório,
**ninguém perde**, sons e voz em português.
Funciona no navegador do celular, tablet ou computador, sem instalar nada.

## Como jogar

**Tela inicial:** toque num carro para escolher (ele buzina e fala o nome).
Os personagens são McQueen, Mate, Sally, Doc e Luigi. Depois toque num dos 3 jogos:

| Jogo | O que a criança faz |
|---|---|
| 🏁 **Corrida** | Segura o dedo na tela para acelerar e arrasta para cima/baixo para pegar estrelas. O Chick Hicks corre junto, mas no final o seu carro sempre ganha 🏆 |
| 🧽 **Lava-jato** | O carro está cheio de lama. É só esfregar o dedo nele até ficar brilhando ✨ (os olhos do carro seguem o dedo) |
| 🎨 **Pintura** | Toca numa tinta e o carro muda de cor, e a voz fala o nome da cor. A ⭐ volta para a cor original. A cor escolhida também aparece na corrida e no lava-jato |

O botão 🏠 sempre volta para o início. Na tela inicial: 🔊 liga/desliga o som e ⛶ abre em tela cheia.

## Como abrir no celular/tablet

1. No GitHub, vá em **Settings → Pages**, escolha a branch e a pasta `/ (root)` e salve.
2. Abra o endereço que aparecer (algo como `https://<seu-usuario>.github.io/jogo-macqueen/`).
3. No celular, use **"Adicionar à tela inicial"** para virar um ícone de app.
   Depois da primeira vez, funciona até sem internet.

Para testar no computador, basta abrir o `index.html` no navegador.

### Dicas
- Melhor com o aparelho **deitado** (paisagem), mas funciona em pé também.
- No iPhone/iPad, use o modo **Acesso Guiado** (Ajustes → Acessibilidade) para a criança
  não sair do jogo sem querer.
- A voz usa a voz do próprio aparelho; se estiver no silencioso, o som não sai.
